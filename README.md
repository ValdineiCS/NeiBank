# 💳 NeiBank

O **NeiBank** é um sistema simples para controle de microcréditos pessoais em desenvolvimento.  
Foi desenvolvido como projeto de prática em **HTML, CSS e está sendo adicionado JavaScript**, com foco em responsividade e boas práticas de organização de código.  

---

## 🚀 Funcionalidades
- 📌 **Cadastrar novos empréstimos** (nome do cliente, valor e data de vencimento).  
- 📊 **Visualizar distribuição em gráficos**.  
- ⏳ **Acompanhar pendências de pagamento**.  
- 📱 **Layout responsivo** (desktop, tablet e celular).  

---

## 🛠️ Tecnologias utilizadas
- **HTML5** → estrutura das páginas  
- **CSS3** → estilos, responsividade (media queries, flexbox)  
- **JavaScript** → lógica e armazenamento de dados (localStorage)

## 📂 Estrutura do projeto
- `index.html` → Dashboard principal  
- `emprestimo.html` → Cadastro de empréstimos  
- `grafico.html` → Visualização de gráficos  
- `pendencia.html` → Lista de pendências  
- `style.css` → Estilos gerais do sistema  
- `script.js` → Lógica e armazenamento  

---

## 📌 Objetivo
Este projeto foi criado como exercício prático para consolidar o aprendizado em **HTML e CSS** e iniciar os primeiros passos no **JavaScript** com manipulação de DOM e armazenamento local.
